# Empty-Time BOOK starts at the clicked Slot; length is Template duration

The member Timetable row is 30 minutes. Clicking 09:30–10:00 with Template duration 60 seeds Booking interval 09:30–10:30 — from the click, not from the template's 09:00 aligned chunk. A When / Search Bar interval must be at least that room's Template duration (equal is allowed) and may be longer; it does not have to be an integer multiple. A 30-minute interval is not Available on a 60-minute room.
